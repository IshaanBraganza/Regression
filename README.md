As the name suggests (or if your confused) I made both a linear regression and polynomial regression model. A linear regression model works on a simple y = mx + c while polynomial regression goes up till the nth degree. The polynomial regression model normalises the x and y input data to make sure the model works as intended for different data sets, and with this model you can give it what degree you want to start with, and what degree you want to end with, and it will automatically go through all the degrees in between and find the best degree for that data set.
